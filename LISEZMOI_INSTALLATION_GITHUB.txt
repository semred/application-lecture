========================================================================
COMMENT DÉPLOYER VOTRE APPLICATION SUR GITHUB PAGES EN 1 MINUTE
========================================================================

Ce dossier contient tous les fichiers COMPILÉS de votre application.

ÉTAPES :
1. Décompressez le contenu de ce fichier ZIP dans un dossier sur votre ordinateur.
2. Allez sur votre dépôt GitHub : https://github.com/semred/application-lecture
3. Téléversez TOUS les fichiers et dossiers (y compris index.html et le dossier assets/) 
   à la RACINE de votre dépôt.
4. Rendez-vous dans : Settings > Pages > Source: "Deploy from a branch", Branch: "main", Folder: "/ (root)" > Save.
5. Ouvrez votre site : https://semred.github.io/application-lecture/

FÉLICITATIONS ! Votre application fonctionne maintenant partout sans mot de passe !
